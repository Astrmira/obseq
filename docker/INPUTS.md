# External inputs for native producers

Set each role to the absolute path of the exact local file or directory consumed by its producer. For containers, bind the parent directory read-only under `/data`. The [role example](../evidence/e7-archived-native-replay-extension-10/INPUT-ROLES.example.json) lists the full roster. Publisher data and designated derived inputs are acquired separately. A publisher URL can serve revised bytes, so check the archived content seals before binding.
