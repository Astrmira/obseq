# Exact nonoverlapping cut repair for selected SUM formulas

This extension admits a narrow single-sheet, disjoint cut of a rectangle into initially blank **and unreferenced** space. A formula is one top-level SUM of unanchored same-sheet scalar A1 or increasing-endpoint rectangular A1 arguments. It allows duplicated or overlapping arguments, and allows a moved formula to refer to an unchanged outside target. Formula dependencies must be acyclic. The admitted literals and cached-independent formula results are nonnegative exact integers; the preflight computes the total under the stated semantics and caps it at 2^53. This makes summation regrouping exact regardless of order in this model. The 100 rewritten-argument cap is a private scope choice, not a claim about application limits.

For source S, displacement δ, and target range R, let H=R∩S. The coordinate-identity image is (R minus H) disjoint union (H+δ). The first term partitions into at most four bands around H (top, bottom, middle-left, middle-right). The second contributes one translated rectangle. Target-space injectivity follows because no original argument touches the destination and the destination does not overlap the source. Preserve **every argument occurrence** before flattening the pieces: duplicates and overlap across arguments intentionally create multiple visits, so a set union across all args is wrong. Each original reference occurrence maps bijectively to its own image. Topological induction over formula hosts preserves values under the stated sum semantics, including blank cells ignored by SUM. The same rule repairs both inbound and moved formula hosts.

The exact geometry uses interval intersection and at most five pieces, never enumerating a covered footprint. The separate semantic guard visits only physically populated authored cells to check formula dependencies and exact value bounds; it can still be quadratic or recursive for dense formula graphs. The bounded native writer is not proposed for very large moves. A pure geometric test includes a rectangle of 4,294,967,296 addresses without allocating cell coordinates; 160 smaller cases verify full **multiplicity** against a literal cell-reference oracle.

Native openpyxl translate=True updates a moved formula's genuinely outside relative input incorrectly and leaves the inbound aggregate unchanged. The staged repair instead moves cells without translation, rewrites admitted formulas, checks manually specified raw OOXML anchors and expressions plus a save/reload structure check, and publishes the repaired copy only after agreement. The source remains byte-identical. Blocked controls include a physically blank destination already referenced by a formula, anchored refs, and MAX. Anchors are intentionally excluded: splitting a range introduces artificial boundaries, and this test does not establish how dollar markers at those boundaries should behave under a future copy. Other functions, cross-sheet/defined references, arrays, tables, dynamic formulas, circular evaluation, strings/errors and general floating-point regrouping are unsupported. No Excel behavior or full-package preservation is inferred.

The optional LibreOfficeDev 26.8.0.0.alpha0 independent recalc compares the original and repaired sheets and requires both formula values [15,97]. It evaluates the resulting serialized file; it does not perform or qualify LibreOffice cutting.

Replay: `python3 -IB check.py | cmp - result.json`; optional `python3 -IB check.py --consumer | cmp - consumer.json`.
