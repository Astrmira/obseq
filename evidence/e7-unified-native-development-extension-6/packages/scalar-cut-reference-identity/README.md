# A narrow same-sheet cut contract for ordinary scalar A1 formulas

The supported semantic question is one disjoint single-sheet cut of a bounded rectangle into initially blank, unreferenced space. The authored workbook admits integer cells and acyclic formulas of the grammar =A1±B2±..., with optional column/row dollar markers and no other syntax. Before cutting, read every physical host and all direct targets. Reject a target in the destination even if that destination cell is blank: this conservative guard avoids preserving an outside cell identity at a coordinate about to be reused. Reject unsupported formula objects/ranges and cycles before any mutation. Named ranges, arrays, tables, dynamic expressions, cross-sheet links, styles and full-package preservation are not qualified. The artifact is an authored test, not a general workbook rewrite service.

Define a coordinate map T that translates each coordinate originally in the source rectangle and is identity elsewhere. Under the preflight conditions it is injective on occupied hosts and referenced coordinates; an empty source target remains an empty translated target and protected outside targets stay untouched. For each formula host h, store its same expression tree at T(h); each reference target x is changed to T(x) regardless of whether the host moves or which dollar markers it uses, and each marker is preserved for future copying. Induction over the original acyclic dependency graph gives equal formula results under the same literal arithmetic and empty-cell semantics. This is a cut, not copy-relative translation.

The native openpyxl fixture exhibits both hazards. With translate=False the moved and inbound formulas keep stale addresses. With translate=True the moved formula's mixed markers shift only selected axes (and an unrelated outside relative input moves spuriously), while inbound expressions are not repaired. The exact repair checks source and repaired formulas by independently reading worksheet XML and matching manually specified token strings for all four formula hosts. It includes a moved formula with an outside input, an initially blank internal target, inbound absolute and mixed targets, and a staged-style fail-closed preflight. Eight cases include the positive treatment and four scope rejections without mutation. The optional LibreOfficeDev 26.8.0.0.alpha0 (2c87e51eeaa2b413ff4ae097b2705eea1995d8e5) path evaluates the authored original and repaired sheets after serialization; it is **not** a LibreOffice cut test. The [official LibreOffice UNO moveRange method](https://api.libreoffice.org/docs/idl/ref/interfacecom_1_1sun_1_1star_1_1sheet_1_1XCellRangeMovement.html) is documented, but the installed headless bundle has neither Python nor Java UNO bindings exposed. No native Calc cut or Microsoft Excel inference is made.

Replay `python3 -IB check.py | cmp - result.json`; optional ordinary recalculation `python3 -IB check.py --consumer | cmp - consumer.json`.
