# Same-name scalar dependency drift can leave a stored computation stale

R124 showed a persisted index whose comparator changed. This contrasting native fixture keeps an independently declared integer function contract and tests materialized result values rather than ordering. SQLite receives the same deterministic user-defined score/1 name with two known coefficient profiles. A STORED generated column, a VIRTUAL generated column and an ad-hoc evaluation refer to that same name. A pinned manifest declares source IDs/values, both semantic profiles, and whether the columns should agree with the current profile.

A closed database copied byte-for-byte from the first profile and reopened with the second exhibits stale STORED results on two rows. VIRTUAL and ad-hoc evaluations match the independent integer oracle for the new profile. Zero stays identical across versions and would miss the drift on its own. The case still passes integrity_check, so structural validity is not a semantic freshness gate. Actual REINDEX on the stored field's index leaves the stale field unchanged: rebuilding a derived structure over stale data cannot refresh the supplier. A controlled UPDATE that rewrites the generated-column source in this isolated trigger-free fixture recomputes the value; committed close/reopen confirms all current-profile expectations.

General gate: bind executable dependencies to a semantic profile independently of schema names or logical database bytes, mark whether each field is evaluated at read time or materialized, and bind persisted derivations to the profile that generated them. For a deliberately historical field, the expected old profile is a declared contract, not an error. For a current field, compare committed reopen results to an independent source-level oracle and rebuild stale dependencies in order. Neither a local test hash nor integrity checks attest arbitrary external dependencies. The fixture update is not an operational recommendation for production schemas with triggers, auditing, side effects or concurrent writers. No elapsed-time claim.

Replay: `python3 -IB check.py | cmp - result.json`.
