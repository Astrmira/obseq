# Prospective bounded JSON navigation experiment
Frozen independently of the author labels. Valid JSON with unique object keys; exact small integer values, strings, booleans, objects, arrays and JSON null. Canonical rooted navigation uses an explicitly typed step, not a generated JSONPath string. At each step, a key requires an object, an index requires an array; report the zero-based index of the first wrong-container, missing-key, or missing-index failure. JSON null encountered before a remaining step is a wrong container, not SQL missing. If the whole path is consumed, report explicit-null with no failing step, or value and exact typed JSON value. Empty path selects root. Arrays use nonnegative zero-based indices. Containers selected at a terminal step are valid values. Object key order is not identity; array order, scalar types and Unicode codepoints are. No duplicate keys, malformed JSON, scientific/fractional number semantics, unpaired surrogates, NUL in object keys, out-of-range native int32 indexes, or negative indexing. This is an authored held-out functional control, not an error/prevalence estimate. All candidate native outputs are sealed before asking for author answers. Blind author answers will be compared with strict JSON type-aware equality (false is not 0). A null-only observer cannot distinguish any of the four non-value classes, by construction.
