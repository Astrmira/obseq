# E3 F10 third source: Census state cartographic boundaries
Official 2024 US Census source https://www.census.gov/geographies/mapping-files/2024/geo/carto-boundary-file.html and original ZIP https://www2.census.gov/geo/tiger/GENZ2024/shp/cb_2024_us_state_20m.zip. These generalized boundaries are not suitable for real-world precision or geographic measurement; here the witness is a vertex of the exact delivered physical geometry, with no real-world-location inference. The plan and its fingerprint were recorded before obtaining ZIP bytes. The data are aggregate public boundaries, not individual locations. No raw attribute, geometry or witness coordinate in the result.
The GDAL 3.10.3 shapefile parser loads physical source WKB via ZIP directly, EPSG:4269, no reprojection. Independent Shapely 2.2.0 / native GEOS 3.14.1 executes precision snap and zero-tolerance covers; this is not an exact-arithmetic theorem about GEOS. The first source outer-ring coordinate remains unsnapped. Original and zero-grid control cover every one of 52 anchors; all 52 outputs pass the row count, per-row geometry kind/dimension, validity and nonempty observer in all five treatment grids. However, 4/52 previously covered anchors become uncovered at the smallest tested grid 1e-9 source degrees; counts across remaining grids 2, 4, 2, 36. None excluded. No monotonicity or prevalence claim; no claim that GEOS grid snapping is buggy. This is a controlled injection and demonstrates why structural validation alone cannot protect this declared preservation contract. Witness ordinal list represented only by SHA256.
Reproduce: place original zip in census.zip, point PYTHONPATH to pinned Shapely 2.2.0, run `python -B run.py census.zip | cmp - RESULT.json`. GDAL uses /usr/bin/python3.
