# When can a partition certify derived-state reuse?

This third native operator differs from rank/top-k: GDAL/GEOS computes areal overlaps of geometries with a changing region. Actual integer scores, production-epoch fields and geometries are persisted in GeoPackage, then closed and reopened. An independent exact integer unit-cell oracle computes expected overlap and threshold membership on a manifest of authored nonempty grid rectangles. The reopened geometry and stable IDs also match the scoped input separately from derived scores and selection. Native intervention arms deliberately choose refresh subsets; they are not spontaneous GDAL defects.

This fixture falsifies a partition-wide latest-epoch or aggregate-only claim. Two rows in the north partition change by opposite amounts, so a completely stale partition initially has the same total overlap as completely current values while choosing the wrong IDs. Refreshing only the first changed row raises the partition maximum produced epoch to current, but the second row is stale and its selection remains wrong. The minimum produced epoch is a sufficient certificate **if every eligible row was inventoried and strictly current ancestry is required**, but it rejects useful semantic-value reuse because some older scores are already exactly correct.

**Data-dependent invalidation.** For an object G and regions A (old) and B (new), its overlap delta is area(G∩(B\A))−area(G∩(A\B)). Under this exact lattice domain the score is reusable iff those two areas agree. The west partition has no affected FIDs even though one member intersects both changed strips; an envelope or intersection-only dirty bit over-invalidates it. Partition-level semantic reuse is justified by a verified all-member cancellation invariant, or by a complete certificate that every changed FID was refreshed. Summing cancellations over the partition is not such a certificate. Refreshing only the two affected geometries reproduces full per-row results and threshold IDs, without claiming all produced epochs are current.

A version tag can be compressed to one per homogeneous coverage set if its homogeneity and scope are certified, not by substituting one latest tag for mixed rows. This experiment captures both semantic freshness and stronger historical production policy, with no logical inference from one to the other. Arbitrary floating geometry, invalid shapes, other CRS, concurrent writes, authority/attestation and speed claims are out of scope. The demonstrated checker already computes exact oracle support; it is not itself a claim of cheaper invalidation.
