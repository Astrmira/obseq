# One benchmark receipt, two independent contracts: lineage and geometry

The manifest specifies stable FIDs, source proposal authority, intended action, before geometry and proposal geometry. Its geometry domain is finite closed unit-grid square unions, and its operation domain is keep versus replace with an authoritative proposal. The manifest fixes two separately scored contracts, not one SQL or byte-equality comparator:

1. **Typed lineage.** Compare the actual action and authority used for each FID to the manifest. A draft used for a replace is incorrect even if it covers the same geometric set. Caller instrumentation supplies the operation receipt; it is not inferring actions from post-state or attesting to an untrusted trace.
2. **Spatial post-state.** Compare actual reopened feature geometry to the author's exact unit-tile set. Unit centers distinguish different finite square unions; an empty native symmetric difference against their reconstruction guards the chosen geometry domain. The expected tiles are independent manifest data, not generated from native relation output.
3. **Representation diagnostic (non-gating).** Raw WKB mismatch is recorded but not considered semantic failure. Area plus envelope is a demonstrated coarse candidate filter, not a substitute for exact spatial set equality.

A native GDAL GeoPackage run crosses two interventions, each with its own negative and positive control. At FID 11 the bad-lineage arm writes an equal-coverage draft when the intended action is KEEP, so spatial equality passes. At FID 12 the bad-spatial arm materializes a different tile set with the same area and envelope while reporting the intended replacement and authority, so lineage passes. The joint arm fails both. The passing arm has WKB differences at FIDs 12 and 13 from reversing square-union constituent order. All runs use real GDAL SetFeature and fresh closed/reopened GeoPackage layers; they deliberately inject erroneous materialization in chosen arms, not claim a spontaneous GDAL defect. Thus neither primary projection can stand in for the other, and failed raw equality is not sufficient to reject the geometry contract.

Reproducibility protocol: freeze domain/tagged data, intended action/authority and identity universe first; generate controlled orthogonal interventions, check exact expectations independently per contract, and retain representation diagnostics and versions separately. Pinning the digest of this manifest lets a future runner reject an accidental fixture mismatch; it is not backend binary attestation. Use a different oracle for arbitrary non-grid geometries, other data types, or truly representation-preserving tasks.

Replay: `/usr/bin/python3 -IB check.py | cmp - result.json` on GDAL 3.10.3 / GEOS 3.13.1. No throughput, policy enforcement, or external-corpus claim.
