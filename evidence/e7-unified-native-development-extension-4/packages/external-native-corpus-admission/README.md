# Independently selected native admission test: QGIS world map does not yet qualify

The selection file was written before inspecting the installed QGIS sample's schema, geometry encodings or native results. It selects the first geometry layer in binary name order and first 12 non-null blobs by integer primary key, not cases chosen for agreement. The installed world map file is read only through SQLite URI and GDAL read-only opens; its recorded SHA-256 pins this local artifact, and the artifact itself is not redistributed. This is a deterministic external-to-the-authored-corpus candidate, not a blinded review or representative sample of maps.

**Actual result: admission withheld.** The selected layer is countries. Eleven selected blobs have the declared standard GeoPackage wrapper and supported two-dimensional Polygon/MultiPolygon WKB grammar. For all eleven, independent stdlib raw coordinate decoding and the GDAL reopened geometry agree on the four envelope values. Every such envelope has a noninteger coordinate: no admitted closed integer-grid rectangle can have that envelope. The twelfth selected FID, 8, has a blob outside the predeclared wrapper. It remains in the cohort as unsupported; the decoder is not extended after seeing it, and its underlying format or validity is not asserted. The observed 11-envelope agreement is only a diagnostic, not acceptance of the overlap operator.

**Missing hook.** The compact authored runner can be reused at the receipt/gate level, but it originally synthesizes each fixture and normalizes native geometries into authored integer rectangles. An actual artifact needs (1) a read-only artifact ingress with stable external layer/FID projection and explicitly supported encodings, and (2) independent area and selection evidence for the native source polygon/CRS/metric contract, ideally author-supplied golden values or a separately qualified exact polygon oracle. Projecting to envelopes would change the workload; using the GEOS evaluation under test as ground truth would make the test circular. This experiment implements only admission and one independent envelope diagnostic, so the original oracle is not patched and no held-out overlap score is reported.

Replay against this installed artifact: `/usr/bin/python3 -IB check.py | cmp - result.json`.
