# Clearance certificates for observed CRS round-trip coordinates

This is a representation-transfer **certificate**, not a projection-analysis error bound. The preregistered holdout uses six pinned QGIS country components and native GDAL/PROJ 4326→3857→4326, persists transformed polygon rings in disposable GeoPackage and verifies the reopened geometry against independent raw WKB. Both endpoint configurations use exact binary64/dyadic semantics. A new probe set uses all exact representable edge midpoints, symmetric 1–256 ULP y offsets at each such midpoint, and a fixed 3×3 bounding-box lattice. The script isolates moving just the point, moving just the edges, and moving both. It neither measures nor bounds an arbitrary continuous CRS transformation.

**Observable certificate.** For one source edge, subtract the source query point to obtain endpoints A,B; subtract the selected target query from target endpoints to obtain C,D. Consider a proof homotopy that interpolates both endpoint pairs linearly (not the actual projection trajectory). Every moving edge point is a convex combination of A,B,C,D. If the origin is outside the exact closed hull for every edge, no moving edge ever crosses the query. The closed polygon loop avoids that point throughout this homotopy, so winding parity is invariant; since the source and target are individually simple, this preserves strict planar inside/outside. The guard cannot certify a source boundary point because the source edge already contains it. Ambiguity means **not certified**, not proof of drift.

A simpler sufficient guard is squared distance from the origin to the original edge > max(squared relative endpoint movements). Every convex combination in the four-endpoint hull is a point on the original edge plus a perturbation of no more than this radius; thus the simple guard implies hull exclusion. The checker calculates segment projection and convex hull membership with exact rational arithmetic (no rounded square root or estimated physical displacement). Relative movements C−A and D−B appropriately account for point/edge cancellation rather than always adding separate absolute margins.

**Results.** Across 339 probes, the full transfer changes 49 categories. It certifies 220 via the scalar radius guard and 281 via the stronger hull guard; none of those certified changes. The remaining 58 are ambiguous, 9 of which actually stay unchanged. Moving only points changes 50 categories and moving only edges changes 44; their exact classifications differ from the joint case at 18 and 53 probes respectively. Exact hexadecimal contrasts are in the receipt. Native Contains and Intersects agree with the independent labels across the original and all three comparison paths. The conclusion is not a GEOS defect or a guarantee over future data.

Scope: single planar simple no-hole components and observed endpoint/query coordinate pairs only; no geodesics, global CRS rounding bounds, continuous curve equivalence, crop/distance/area, tolerance policy or latency claims. Intermediate loops need only avoid the point for the parity argument; no claim of their geometric validity is made. Replay: `/usr/bin/python3 -IB check.py | cmp - result.json`.
