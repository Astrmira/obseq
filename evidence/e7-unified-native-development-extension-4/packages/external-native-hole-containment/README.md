# Holed polygon components: exact independent admission and boundary semantics

The held-out policy was fixed before identifying any eligible component or running native predicates. It reuses the pinned installed QGIS world map, takes the next up-to-96 non-null country FIDs above 21 and selects the first four FIDs in that window with a qualifying holed component, in storage component order. Probe locations are determined by the predeclared vertex, exactly representable edge-midpoint, one-ULP-neighbor and grid rules. Source SQLite and GDAL opens are read only. This tests newly admitted holed components, not the previously unsupported wrapper or whole MultiPolygon unions.

**Independent exact scope.** Parse standard raw GeoPackage WKB and treat finite binary64 coordinates as exact dyadic rationals. Each ring is checked independently for simplicity, unique vertices, nonzero signed area and noncollinear neighboring edges. Pairwise segment checks reject all inter-ring boundary contacts and crossings. Under those conditions, one strict-inside witness places a hole's entire connected ring inside the shell by the Jordan curve theorem. Between holes, disjoint boundaries plus mutual exterior witnesses exclude nesting. The contract accepts only bounded-size simple, disjoint, unnested holes. No native validity or native geometry predicate provides oracle truth.

Half-open ray parity with exact orientation determines each ring's interior, with exact on-segment boundary checked separately first. Shell and hole boundaries both reject strict Contains and accept Intersects, whereas a true hole interior rejects both. The native comparator independently obtains each selected component from the reopened GDAL source and checks that all ring coordinates match the raw oracle input. The oracle is orientation-sign independent under this subset.

Four components qualified (five holes total) after scanning 65 FIDs, 61 of which had no qualifying component; the cohort file names all scanned rows and their admission status. There were 2,763 probes: 525 outer-shell boundary, 40 hole boundary, 239 hole interior, 1,034 polygon interior and 925 outside the shell. Native GDAL/GEOS Contains and Intersects agree with all exact outcomes. Positive external support is for this operator and subset only: touching rings, nested or invalid holes, wrapper extensions, complete multipolygon unions, CRS transforms, geodesics, metrics and latency are unsupported. No external file contents are bundled.

Replay: `/usr/bin/python3 -IB check.py | cmp - result.json`.
