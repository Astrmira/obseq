# Cross-engine reuse, and where a freshness gate is too narrow

This holdout imports the prior semantic harness's digest, check and independent oracle functions **unchanged**. A new adapter handles actual XLSX/openpyxl streaming, original spreadsheet formula and cache observations, and pandas materialization/ranking. It emits the existing stage receipt (manifest and canonical source rows, ambient runtime epoch, exact eligible derived score values and stable selected IDs). The holdout changes dataset, storage system, rank execution engine, physical input order and quotas, including a zero quota. The oracle is still the same exact small eligible-subset enumeration over the manifest, not an adapter-specific expected list.

Two native pandas tie refinements choose different legal outputs across physical workbook orders and pass the same checks. Using all old XLSX caches fails the derived-score and allowed-output gates, while the same source-data binding passes. The OOXML cache values are authored and independently checked against original formula text and source values, not inferred to be fresh by opening the workbook. No Excel or LibreOffice recalc claim.

**Minimal contract boundary.** A fourth adapter reads old cache values only where the row is provably invariant to the epoch change (zero sensitivity). It correctly passes the original **semantic-value** freshness gate. Its entire base receipt is identical to the all-current computed route, so no validator over that receipt can additionally determine which route generated the values. If the benchmark requires **production-epoch provenance** rather than current semantic equivalence, add checked per-stable-ID produced epoch evidence (or a producer-certified partition of IDs by epoch) with complete coverage. In this controlled fixture the extended strict gate distinguishes the routes. The provenance observation is explicitly adapter instrumentation bound to authored cache inputs, not attestation that arbitrary third-party workbook caches carry trustworthy production history. Do not make passing equivalent cached values a defect in the existing contract.

Replay: `python3 -IB check.py | cmp - result.json`. The receipt records the shared module digest and the installed library versions. The transfer qualifies one operator domain, not arbitrary XLSX formulas, SQL, or throughput.
