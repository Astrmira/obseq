# Preflight and stage a scoped workbook structural move

R113 established that native array/table formula move_range can have a partial effect before raising an exception. This fixture tests a practical repair procedure rather than treating a caught exception as a rollback. The admitted domain is deliberately narrow: disjoint same-sheet cuts into blank unowned space, no movement of the known unchanged input ranges, authored literal values and supported array/data-table declarations. Any ordinary formula in the sheet is rejected by this minimal adapter rather than assuming references are safe. The fixture is not a general workbook editor.

First independently model source and destination coordinates for each move. Reject bounds, source/destination self-overlap, strict partial intersection with a declared output group, destination intersection with **any** declared output group (even cells absent from the stored cell map), destination content, or a source touching the fixture's unchanged input range. If a whole output group is admitted, its output ref follows the group while untouched inputs stay fixed. Apply to a disposable workbook copy with native move_range, explicitly repair declared refs and compare a staged save/reload to the independently advanced structural model. A separate raw OOXML witness checks the resulting formula anchors and ranges. Only publish the verified staged file. This concerns semantic patch staging, not crash-fsync durability, concurrent editing or supported Excel recalculation.

The eight native test arms include two admitted moves in one successful batch, an attempted write into an apparently blank data-table member, and two late-rejection controls. A second move rejected by preflight and a deliberately injected late staged-write mismatch each leave the preexisting target bytes unchanged even after real mutations on the working copy. This rules out implementing the batch as a sequence of direct writes. Coordinate-set enumeration suits this authored small fixture; a production-scale implementation would need range intersection and an explicitly qualified larger formula/style/feature model.

Replay: `python3 -IB check.py | cmp - result.json` with openpyxl 3.1.5.
