# Workbook clone: formula spelling, scope ownership, and bound target are independent

The supported contract is a particular authored sheet clone: for simple local names bound to cells on the source sheet, the clone should resolve the same name to the corresponding clone cell. The source sheet and true workbook-global names retain their original semantics. This is not a claim that openpyxl promises to clone names, or that every defined name should be retargeted.

All three native openpyxl writer cases have identical `=Marker*2` in the source and clone, and reorder the clone to the first workbook position before save. The independent graph checker reads raw workbook XML and package relationships: it resolves each sheet's worksheet part to verify the formula, uses actual workbook sheet order to interpret zero-based localSheetId, and applies local-before-global scope lookup. Default copying omits the clone-local Marker, so the only remaining applicable target is Global!A1. Merely cloning the local declaration makes it local to the correct clone position, yet its explicit target is still Template!A1. Retargeting the declaration resolves Copy!A1. The original always remains Template!A1. Thus formula text alone, or text plus name/scope existence, is not sufficient for the stated reference-identity contract.

The three target cells are assigned different integers to make wrong binding observable; if the sheet values were still duplicates, matching calculated values could hide binding drift. The optional independent LibreOfficeDev 26.8.0.0.alpha0 (2c87e51eeaa2b413ff4ae097b2705eea1995d8e5) recalc asserts Copy outputs of 200, 20 and 40 respectively and original output 20 in all cases. The relevant repair for an anchored simple name is graph-based: preserve local ownership, redirect source-internal edges to the mapped clone, preserve true external edges, then serialize scope position last. Dynamic/relative names, ranges crossing sheet scopes, external-workbook links and Microsoft Excel behavior are not established here.

Replay XML/writer checks: `python3 -IB check.py | cmp - result.json`. Optional independent native cache replay: `python3 -IB check.py --consumer | cmp - consumer.json`.
