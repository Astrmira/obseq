# A CRS round trip changes exact boundary identity without a predicate failure

This is a separate representation-transfer test, not a rerun of the earlier single-representation point cohort. The preregistered policy uses six fixed FIDs from the installed pinned QGIS world map and original no-hole simple components within a strict longitude/latitude range. Native GDAL/PROJ transforms every stored vertex and defined probe through EPSG:4326 → EPSG:3857 → EPSG:4326 using traditional GIS axes. It writes the output rings to a disposable GeoPackage; reopened GDAL confirms EPSG:4326 while independent raw SQLite WKB reads and checks the actual coordinate bits. No geographic source is modified.

The independent exact dyadic oracle verifies ring simplicity and exact planar containment **separately** on the old and new coordinates, with no shared native predicate or tolerance. The direct controls are transformed vertices. The main witnesses are exactly representable edge midpoints and their immediate binary64 y-neighbors; a midpoint is exactly on its original edge, not just visually close. result.json includes exact hex point/edge endpoints and exact rational nonzero orientation for witnesses where the old midpoint no longer lies on its transformed edge.

**Observed difference.** In native GDAL 3.10.3 / PROJ 9.6.0, 53 of 65 distinct vertices change coordinate values. All 65 transformed vertex probes still classify as boundary. Of 15 original exact edge midpoints, 14 change category after the round trip: 11 exterior and three interior. Of 30 one-ULP probes, 12 change category. Across all 110 probes, both native Contains and Intersects agree with the reference for each representation separately. The cross-representation drift is therefore not a native predicate error in this test. An invariant CRS ID, a vertex-only control and exact agreement inside each representation all fail to prove original boundary identity.

For reproducibility, report the binding from predicate to exact stored representation, transform pipeline/axis order and query-coordinate production path. Do not reuse the source category as a target truth without a separate invariance proof. This is a scoped planar binary64 comparison on simple individual components; it does not test projection of geodesics, continuous edge shapes, physical distances, area, native clipping, unsupported wrappers, tolerance design or timing. The digest pins the local external file without redistributing it.

Replay: `/usr/bin/python3 -IB check.py | cmp - result.json`.
