# Compact native semantic-conformance corpus

Run the whole corpus with `python3 -IB run.py | cmp - result.json`. The frozen manifest has one development fixture and one separately authored holdout per native route. These are deliberately constructed transfer holdouts, not a blinded random sample. The runner consumes each named contract in the same receipt shape: observed stable-ID primary input rows, per-ID derived values, output stable IDs, version tuple and exact manifest digest. Each gate is genuinely separate:

- **Artifact** compares canonical observed source rows against declared ground truth. The SQLite adapter reads native primary rows, openpyxl streams native worksheet values, and GDAL independently reopens GeoPackage and reconstructs scoped rectangle geometry and IDs.
- **Derived values** compare exactly against small stdlib-only numerical or tile-set oracles. Current profiles come from the manifest, not from known behavior of the adapters. SQLite UDF-based score, pandas arithmetic, and GEOS overlay follow different native implementations from the reference.
- **Allowed output** enumerates the legal ranking witnesses independently or computes threshold membership from independent integer cell sets. It does not pin a buggy result or require one arbitrary tied winner.

Default denotes an explicit legacy/materialized operational strategy in this experiment: older SQLite scores, authored prior XLSX calculation caches, or old spatial region. It is not a claim that the installed libraries automatically make those choices. The current strategies select the required profile. The mixed scenario runs current SQLite and GeoPackage but the cached XLSX route. Its input bindings all pass; the XLSX scores/output fail, so the runner retains the prior accepted receipt instead of publishing a partial batch. The all-current run passes all nine held-out gates and replaces the prior receipt only after a staged write. The all-default control fails state/output in all three holdouts. The staging test covers only publication of the evaluation receipt, not atomic changes to multiple production artifacts or durability under crashes/concurrent execution.

**Unsupported dimensions.** No external or sampled production corpus; no Excel/LibreOffice formula evaluator or arbitrary cache freshness; no SQL operator families beyond scoped integer profile and top-k; no arbitrary CRS or floating/invalid geometry; no attestations or producer epoch claims; no cross-version rate or performance measurement. A new adapter needs its own versioned independent oracle and explicit eligibility/representation rules. The fixed-size operator witnesses allow exact enumeration; no asymptotic claims for arbitrary SQL or geometry benchmarks.

Default Python requires SQLite, openpyxl and pandas. The spatial adapter uses both GDAL and GEOS via /usr/bin/python3. result.json supplies the actual native version tuples and 12 receipts (three development, nine held-out executions).
