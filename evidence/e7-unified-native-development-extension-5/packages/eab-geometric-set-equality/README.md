# Geometry interchange: stable identity, cheap candidates, and exact set equality

This in-scope synthetic corpus asks whether two reopened feature geometries cover exactly the same set of points. The author defines each feature as a finite union of **closed** unit grid squares. Distinct square sets imply distinct geometric sets because the center of any differing square belongs to only that square. Identical square sets are sufficient by construction. The exact independent oracle is therefore a set of integer tile coordinates, not GIS normalization, WKB, or the result of overlay itself.

The checker constructs polygons by GEOS union in two opposite orders, writes GDAL GeoPackage features, closes the writer and reopens the file, and compares all 2,016 pairs by stable FID. Native empty symmetric difference matches the independent author oracle on every pair. Plain WKB and the tested native OGR Equals only recognize 3 of 32 equal pairs. The coarse exact envelope+area signature recognizes all oracle-equal pairs but retains 24 distinct pairs as candidates. This includes an authored pair of different tile occupancies with identical envelope and area. Every claimed geometry match is evaluated independently from serialization and diagnostic group fields.

This suggests a benchmark stratum with both representation-preserving and geometry-set-preserving contracts rather than one implicit equality. A tile occupancy oracle is exact for this slice; an external corpus would need author-side geometry ground truth or certified construction from specified transforms to use this oracle. Arbitrary real-world polygons, invalid geometry, non-linear curves, non-grid overlay and CRS changes are unqualified. An explicit line control shows why zero symmetric-difference area is not a general substitute for empty difference. No performance claim or external corpus qualification.

Replay with GDAL 3.10.3 / GEOS 3.13.1: `/usr/bin/python3 -IB check.py | cmp - result.json`.
